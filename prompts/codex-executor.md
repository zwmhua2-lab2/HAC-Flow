# 本地 Codex 标准执行指令

请执行 GitHub 仓库 [仓库名] 的 Issue #[N]。
仓库本地路径：[填入你的本地绝对路径]

【强制前置检查】
在执行代码前，请确认该 Issue 是否拥有 `ready` 标签。如果没有 `ready` 标签，请立刻停止任务并报告：“执行失败：任务卡未通过需求审查”。

【执行要求】
如果有 ready 标签：
1. 基于最新 main 创建 task/[N] 分支。
2. 严格遵守 Issue 中的目录白名单，严禁越权修改。
3. 先把 Given/When/Then 验收标准原样写成单元测试，再写业务代码；绝对不要改测试迁就实现。
4. 跑通测试后提交 PR。PR 描述写明：改动文件、测试结果、未验证项、最可能出错的 2 个点。
