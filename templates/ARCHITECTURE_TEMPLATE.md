## 3. 模式库（按失败模式选用；不适用的整条删除）
- **P1 请求路径零外部调用（读写分离）**：对外服务只读本地已准备好的数据，抓取/计算在另一个组件。适用：对外服务依赖慢或不稳定的上游。验证：测试（上游挂死时接口仍快速返回）+ 扫描（服务目录不得 import 外部 client、不得出现网络调用）。
- **P2 新鲜度标注**：响应带 `as_of` 与 `age_seconds`；超过【填：阈值】返回明确的"陈旧"状态，描述"当前"的内容置空；不 500，不悄悄给旧数据。适用：对外展示会过期的数据。验证：测试。
- **P3 退避**：遇 429/限流/封禁信号立即结束本周期；遵守 Retry-After，没有则至少退避【填：秒】；绝不立即重试。适用：调用限流的第三方 API / 爬虫。验证：测试。
- **P4 数字由代码算，LLM 只叙述**：数值全部由确定性代码计算；叙述中每个数字必须出现在输入 facts 里；设禁用词表（只增不减）；校验失败则丢弃叙述、数值照常发布。适用：产品里有 LLM 输出。验证：测试（校验器）+ 【填：黄金样本命令】。
- **P5 数据源冻结检测**：数据源返回的最新时间戳落后 now 超过【填：时长】，视为失败。适用：依赖外部实时数据。验证：测试。
